Thiết lập trang Đăng bài

Chỉ làm một lần trên mỗi máy (điện thoại hoặc máy tính). Mất khoảng 5 phút.

Bước 1. Tạo "chìa khóa" GitHub (token)

Token là một mật khẩu riêng cho phép trang này cất bài vào kho mã của Vườn Khai Tâm. Trang này sẽ khóa token lại bằng mã PIN của bạn.

  1. Mở trang tạo token của GitHub (đăng nhập bằng tài khoản GitHub của Vườn Khai Tâm).
  2. Token name: gõ dang-bai. Expiration: chọn 1 năm (366 days) hoặc ngắn hơn.
  3. Repository access: chọn Only select repositories, rồi chọn kho vuonkhaitam.
  4. Permissions › Repository permissions: đặt Contents = Read and write, Actions = Read-only. Metadata tự có Read-only.
  5. Bấm Generate token, rồi bấm nút sao chép token (chuỗi bắt đầu bằng github_pat_).

Bước 2. Đặt mã PIN

Ít nhất 6 chữ số. Mỗi lần mở trang Đăng bài chỉ cần nhập PIN. Nhập sai 5 lần liên tiếp, máy này sẽ xóa token để an toàn.

Bước 3. Danh sách từ nhạy cảm

Những từ không bao giờ được xuất hiện trên web. Trước khi đăng, trang này sẽ dò và chặn lại nếu bài có các từ này. Danh sách chỉ lưu trên máy này, không bao giờ gửi lên GitHub.

Ví dụ: tên con, tên ở nhà, tên trường, lớp, tên thầy cô, tên ấp, xã… Mỗi từ một dòng.
